# 飞书配置

## 1. 建企业自建应用

飞书开放平台创建一个企业自建应用，获得：

- App ID
- App Secret

应用需要能够读取/更新目标多维表格，并读取/上传素材。具体权限名称以飞书开放平台当前控制台展示为准，至少覆盖：

- 多维表格记录读取
- 多维表格记录更新
- 多维表格字段读取
- 云文档/素材下载
- 素材上传

发布应用后，把这个应用添加为目标多维表格的文档应用/协作者。

## 2. 建字段

建议直接按以下名称：

- 标题：文本
- 文案：多行文本
- 图片：附件
- 生成二维码：复选框
- 二维码：附件
- 链接：超链接
- 发布ID：文本
- 发布状态：单选
- 错误信息：多行文本

“发布状态”建议预先创建：

- 生成中
- 待扫码
- 素材处理中
- 已拉起小红书
- 生成失败

## 3. 配飞书自动化

触发条件：

`当“生成二维码”变为勾选`

动作：

发送 HTTP 请求到：

`POST https://你的域名/api/v1/publish/from-record`

Header:

`Authorization: Bearer 你的BRIDGE_TOKEN`

JSON Body：

```json
{
  "app_token": "目标多维表格 app_token",
  "table_id": "当前数据表 table_id",
  "record_id": "使用自动化里的“当前记录 ID”变量"
}
```

这里最容易填错的是 `record_id`：必须使用自动化运行时的当前记录 ID，不是固定值。

## 4. 第一次测试

先只放 1 条测试笔记和 2 张测试图，不要一上来批量跑。

成功标准：

- 发布状态先变成“生成中”
- 数秒后变成“待扫码”
- 二维码字段出现图片
- 链接字段出现“手机扫码发布”
